일본어 문법 전체 정리본
형식: 번호. 문법 / 접속형 / 뜻 / 뉘앙스 / 예문 / 해석
주의: 스캔본 기반으로 정리했으며, 손글씨 메모는 제외했습니다. 일부 예문은 원문 판독이 애매한 부분을 학습용 자연문으로 보강했습니다.

1. あげく
접속형: Vた + あげく / Nの + あげく
뜻: ~한 끝에, 결국 ~하고 말았다
뉘앙스: 오랜 고민·고생·논의 끝에 나온 결과. 보통 부정적 결과.
예문: 太郎はお金のことや友人の問題でさんざん親に心配をかけたあげく、とうとう家を出てしまった。
해석: 타로는 돈 문제와 친구 문제로 부모에게 실컷 걱정을 끼친 끝에, 결국 집을 나가 버렸다.
예문: この問題については、長時間にわたる議論のあげく、結論は先送りされた。
해석: 이 문제는 장시간 논의 끝에 결론이 미뤄졌다.

2. あまり
접속형: V普通形 + あまり / いA + あまり / なAな + あまり / Nの + あまり
뜻: 지나치게 ~해서, 너무 ~한 나머지
뉘앙스: 감정·상태가 너무 강해서 평소와 다른 결과가 나옴.
예문: 合格の知らせを聞いて、彼女はうれしさのあまり泣き出した。
해석: 합격 소식을 듣고 그녀는 너무 기쁜 나머지 울음을 터뜨렸다.
예문: 試験の問題は易しかったのに、考えすぎたあまり間違えてしまった。
해석: 시험 문제는 쉬웠는데 지나치게 생각한 나머지 틀렸다.

3. 以上（は）
접속형: V普通形 + 以上（は） / Nである + 以上（は） / なAである + 以上（は）
뜻: ~한 이상은, ~인 이상은
뉘앙스: 앞 조건이 성립하므로 뒤의 책임·의무가 당연함.
예문: 約束した以上、守るべきだと思う。
해석: 약속한 이상 지켜야 한다고 생각한다.
예문: 学生である以上、勉強を第一にしなさい。
해석: 학생인 이상 공부를 최우선으로 하세요.

4. 一方（で）
접속형: V普通形 + 一方（で） / いA + 一方（で） / なAな + 一方（で） / Nである + 一方（で）
뜻: ~하는 한편으로, ~인 반면에
뉘앙스: 서로 다른 두 측면을 대조.
예문: いい親は厳しく叱る一方で、誉めることも忘れない。
해석: 좋은 부모는 엄하게 꾸짖는 한편 칭찬도 잊지 않는다.
예문: 一人暮らしは寂しさを感じることが多い一方、気楽なよさもある。
해석: 혼자 사는 것은 외로움도 많지만 편한 장점도 있다.

5. （た）上で
접속형: Vた + 上で / Nの + 上で
뜻: ~한 후에, ~한 다음에
뉘앙스: 앞 행동을 완료한 뒤 그 결과를 바탕으로 뒤 행동을 함.
예문: 詳しいことはお目にかかった上で、説明いたします。
해석: 자세한 것은 직접 뵌 후 설명드리겠습니다.
예문: どの大学を受験するか、両親との相談の上で、決めます。
해석: 어느 대학을 볼지는 부모님과 상담한 후 정하겠습니다.

6. 上で
접속형: V辞書形 + 上で / Nの + 上で
뜻: ~하는 데 있어서, ~함에 있어
뉘앙스: 어떤 목적·행위에서 중요한 조건이나 관점을 말함.
예문: 食料品の保存の上で、次のことに注意してください。
해석: 식료품 보관에 있어서 다음 사항에 주의해 주세요.
예문: 今度の企画を成功させる上で、ぜひ皆の協力が必要なのだ。
해석: 이번 기획을 성공시키는 데 모두의 협력이 필요하다.

7. 上は
접속형: V辞書形 + 上は / Vた + 上は
뜻: ~한 이상은
뉘앙스: 결심·각오가 강함. 이렇게 된 이상 당연히 해야 한다.
예문: 親元を離れる上は、十分な覚悟をするべきだ。
해석: 부모 곁을 떠나는 이상 충분한 각오를 해야 한다.
예문: 実行する上は、十分な準備が必要だ。
해석: 실행하는 이상 충분한 준비가 필요하다.

8. 得る（うる／える）
접속형: Vます形語幹 + 得る / Vます形語幹 + 得ない
뜻: ~할 수 있다, ~할 가능성이 있다
뉘앙스: 능력보다 가능성. 그런 일이 일어날 수도 있음.
예문: この事故はいつでも起こり得ることとして十分注意が必要だ。
해석: 이 사고는 언제든 일어날 수 있는 일로 충분한 주의가 필요하다.
예문: 彼が事件の現場にいたなんて、そんなことはあり得ない。
해석: 그가 사건 현장에 있었다니 그런 일은 있을 수 없다.

9. おそれがある
접속형: V辞書形 + おそれがある / Nの + おそれがある
뜻: ~할 우려가 있다
뉘앙스: 좋지 않은 가능성에 대한 경고. 공지·뉴스체.
예문: この地震による津波のおそれはありません。
해석: 이 지진으로 인한 쓰나미 우려는 없습니다.
예문: この薬は副作用のおそれがあるので、医者の指示に従って飲んでください。
해석: 이 약은 부작용 우려가 있으니 의사의 지시에 따라 복용하세요.

10. 折（に）
접속형: V辞書形 + 折に / Vた + 折に / Nの + 折に
뜻: ~할 때, ~하는 기회에
뉘앙스: 정중하고 딱딱한 표현. 기회가 있을 때.
예문: このことは今度お目にかかった折に詳しくお話しいたします。
해석: 이 일은 다음에 뵈었을 때 자세히 말씀드리겠습니다.
예문: 先月北海道に行った折、偶然昔の友達に会った。
해석: 지난달 홋카이도에 갔을 때 우연히 옛 친구를 만났다.

11. 甲斐があって
접속형: Vた + 甲斐があって / Nの + 甲斐があって
뜻: ~한 보람이 있어서
뉘앙스: 노력·시간·돈을 들인 결과 좋은 성과가 나옴.
예문: この子は教えたことはすぐ覚えるので、教えがいがある。
해석: 이 아이는 가르친 것을 바로 외우므로 가르칠 보람이 있다.
예문: 時間とお金を使って遠くまで来たかいもなく、名物の桜はほとんど散ってしまっていた。
해석: 시간과 돈을 들여 멀리 왔지만 보람도 없이 벚꽃은 거의 져 있었다.

12. かぎり（は）
접속형: V辞書形 + かぎり / Vている + かぎり / Nである + かぎり
뜻: ~하는 한, ~인 한
뉘앙스: 조건이 유지되는 동안 뒤 내용도 성립.
예문: 小川氏がこの学校の校長でいるかぎり、校則は変えられないだろう。
해석: 오가와 씨가 이 학교 교장으로 있는 한 교칙은 바뀌지 않을 것이다.
예문: 体が丈夫なかぎり、思い切り社会活動をしたいものだ。
해석: 몸이 건강한 한 마음껏 사회활동을 하고 싶다.

13. かぎり
接続形: V辞書形 + かぎり / V可能形 + かぎり / Nの + かぎり
뜻: ~하는 한, ~할 수 있는 한
뉘앙스: 가능한 범위 내에서 최대한.
예문: さあ、いよいよ明日は入学試験だ。力のかぎり頑張ってみよう。
해석: 자, 드디어 내일은 입학시험이다. 힘껏 노력해 보자.
예문: できるかぎりのことはいたしますから。
해석: 가능한 한의 일은 하겠습니다.

14. かぎりだ
접속형: いA + かぎりだ / なAな + かぎりだ
뜻: 너무 ~하다, ~하기 그지없다
뉘앙스: 감정의 정도가 매우 큼. 문어적.
예문: 明日彼が3年ぶりにアフリカから帰ってくる。うれしいかぎりだ。
해석: 내일 그가 3년 만에 아프리카에서 돌아온다. 너무 기쁘다.
예문: この頃若い人ははっきりと自己主張する。うらやましいかぎりだ。
해석: 요즘 젊은 사람들은 자기주장이 뚜렷하다. 부럽기 그지없다.

15. かぎりでは
접속형: V辞書形 + かぎりでは / Vた + かぎりでは
뜻: ~의 한도 내에서는, ~하는 바로는
뉘앙스: 자신이 알고 있거나 조사한 범위 안에서 판단.
예문: ちょっと話したかぎりでは、彼はいつもとまったくかわらないように思えた。
해석: 잠깐 이야기해 본 바로는 그는 평소와 전혀 다르지 않아 보였다.
예문: 今回の調査のかぎりでは、この問題に関する外国の資料はあまりないようだ。
해석: 이번 조사 범위에서는 이 문제 관련 외국 자료가 별로 없는 듯하다.

16. かける
접속형: Vます形語幹 + かける
뜻: ~하다가 말다, 막 ~하려고 하다
뉘앙스: 동작이 시작되었지만 완료되지 않음.
예문: 母は夕食を作りかけて、長電話をしている。
해석: 어머니는 저녁을 만들다 말고 긴 전화를 하고 있다.
예문: こんなところに食べかけのりんごを置いて、あの子はどこへ行ったのだろう。
해석: 이런 곳에 먹다 만 사과를 두고 그 아이는 어디로 간 걸까.

17. がたい
접속형: Vます形語幹 + がたい
뜻: ~하기 어렵다, ~할 수 없다
뉘앙스: 심리적·도덕적·감정적으로 하기 어려움. 딱딱한 표현.
예문: あの元気な太郎が病気になるなんて信じがたいことです。
해석: 그 건강한 타로가 병에 걸리다니 믿기 어려운 일입니다.
예문: 弱い者をいじめるとは許しがたい行為だ。
해석: 약자를 괴롭히다니 용서하기 어려운 행위다.

18. ~が~だけに
접속형: NがNだけに / 普通形 + だけに
뜻: ~가 ~인 만큼
뉘앙스: 앞의 성질·상황 때문에 뒤 결과가 더 강하게 느껴짐.
예문: 母は今年93歳になった。今は元気だが、歳が歳だけに、病気をすると心配だ。
해석: 어머니는 올해 93세다. 지금은 건강하지만 나이가 나이인 만큼 병에 걸리면 걱정된다.
예문: 事が事だけに、黙って聞いていることはできない。
해석: 일이 일인 만큼 가만히 듣고 있을 수 없다.

19. がち
접속형: Vます形語幹 + がち / N + がち
뜻: 자주 ~하다, ~하기 쉽다, ~하기 십상이다
뉘앙스: 좋지 않은 경향이 자주 나타남.
예문: 田中さんは留守がちだから、電話してもいないことが多い。
해석: 다나카 씨는 집을 자주 비워서 전화해도 없는 일이 많다.
예문: 環境破壊の問題は自分の目に迫ってこないと、無関心になりがちである。
해석: 환경 파괴 문제는 눈앞에 닥치지 않으면 무관심해지기 쉽다.

20. （か）と思うと
접속형: Vた + かと思うと / V辞書形 + かと思うと
뜻: ~했다고 생각한 순간, ~하자마자
뉘앙스: 앞 동작 직후 바로 뒤 동작이 일어남. 빠른 변화에 놀람.
예문: あの子はやっと勉強を始めたと思ったら、もう居眠りをしている。
해석: 그 아이는 겨우 공부를 시작했다 싶더니 벌써 졸고 있다.
예문: うちの子供は学校から帰ってきたかと思うと、いつもすぐ遊びに行ってしまう。
해석: 우리 아이는 학교에서 돌아왔다 싶으면 바로 놀러 가 버린다.

21. か~ないかのうちに
접속형: V辞書形 + か + Vない形 + ないかのうちに
뜻: ~하자마자, 채 ~되기도 전에
뉘앙스: 거의 동시에 일어나는 빠른 변화.
예문: 彼はいつも終了のベルが鳴ったか鳴らないかのうちに、教室を飛び出していく。
해석: 그는 항상 종료 벨이 울리자마자 교실을 뛰쳐나간다.

22. かねない
접속형: Vます形語幹 + かねない
뜻: ~할 수도 있다, ~하게 될 수도 있다
뉘앙스: 나쁜 결과가 생길 가능성.
예문: そんな乱暴な運転をしたら事故を起こしかねないよ。
해석: 그렇게 난폭하게 운전하면 사고를 낼 수도 있다.

23. かねる
접속형: Vます形語幹 + かねる
뜻: ~하기 어렵다, ~할 수 없다
뉘앙스: 정중하게 거절하거나 곤란함을 표현.
예문: ただ今のご説明では、私どもとしては納得しかねます。
해석: 지금 설명만으로는 저희로서는 납득하기 어렵습니다.

24. かのように
접속형: 普通形 + かのように / Nである + かのように
뜻: ~인 것처럼
뉘앙스: 실제는 아니지만 그렇게 보임.
예문: 4月になって雪が降るなんて、まるで冬が戻ってきたかのようです。
해석: 4월에 눈이 오다니 마치 겨울이 돌아온 것 같다.

25. からいうと
접속형: N + からいうと
뜻: ~만 본다면, ~를 생각하면, ~로 봐서
뉘앙스: 특정 관점에서 판단.
예문: 教師の私の立場からいうと、試験はあまり多くない方がいいのです。
해석: 교사인 제 입장에서 보면 시험은 너무 많지 않은 편이 좋습니다.

26. からして
접속형: N + からして
뜻: 우선 ~부터
뉘앙스: 대표 예시 하나만 봐도 전체가 그렇다는 느낌.
예문: この職場には時間を守らない人が多い。係長からしてよく遅刻する。
해석: 이 직장에는 시간을 안 지키는 사람이 많다. 계장부터 자주 지각한다.

27. からすると
접속형: N + からすると
뜻: ~입장에서 본다면
뉘앙스: 어떤 입장·관점에서 판단.
예문: 米を作る農家からすると、涼しい夏はあまりありがたくないことだ。
해석: 쌀 농가 입장에서 보면 서늘한 여름은 별로 달갑지 않다.

28. からといって
접속형: 普通形 + からといって
뜻: ~라고 해서
뉘앙스: 앞 이유만으로 뒤 결론이 반드시 성립하지 않음.
예문: アメリカに住んでいたからといって、英語がうまいとは限らない。
해석: 미국에 살았다고 해서 영어를 잘한다고는 할 수 없다.

29. 気味
접속형: Vます形語幹 + 気味 / N + 気味
뜻: 왠지 ~한 느낌, 약간 ~기미
뉘앙스: 좋지 않은 상태가 약간 있음.
예문: 今日はちょっと風邪気味なので、早めに帰らせてください。
해석: 오늘은 조금 감기 기운이 있어서 일찍 돌아가게 해 주세요.

30. きらいがある
접속형: V辞書形 + きらいがある / Nの + きらいがある
뜻: ~하는 경향이 있다
뉘앙스: 바람직하지 않은 경향을 지적.
예문: あの人の話はいつも大げさになるきらいがある。
해석: 저 사람 이야기는 항상 과장되는 경향이 있다.

31. きり
접속형: Vた + きり / N + きり
뜻: ~인 채, ~한 채
뉘앙스: 그 뒤로 상태가 계속됨. 기대한 변화가 없음.
예문: 彼女には去年一度会ったきりです。
해석: 그녀와는 작년에 한 번 만난 것이 전부입니다.

32. きる / きれる / きれない
접속형: Vます形語幹 + きる / きれる / きれない
뜻: 완전히 ~하다 / 전부 ~할 수 있다 / 다 ~할 수 없다
뉘앙스: 끝까지 완료하거나 한계까지 도달.
