# Contributing

## 수정 순서

1. `data/collections.json`에서 대상 단어장의 `dataFile`을 찾습니다.
2. 해당 `data/wordbooks/session-XXX.json` 파일에서 항목을 수정합니다.
3. 같은 변경이 CSV·검수 목록·통계에 영향을 주면 관련 파일도 함께 갱신합니다.
4. `npm test`를 실행합니다.

대량 재수집은 `npm run import`로 수행하세요. 가져오기 스크립트는 생성 파일을 덮어쓰므로, 수동 수정이 있다면 먼저 별도 브랜치나 커밋으로 보존하는 것이 좋습니다.

## 품질 기준

- 일본어 표기는 원문의 신자체를 우선합니다.
- 읽기는 가급적 히라가나로 적습니다.
- 한국어 뜻은 짧은 기본 뜻을 먼저 둡니다.
- 다의어를 카드로 나눌 때 `nuance`를 반드시 적습니다.
- 추정으로 보완한 값은 바로 `ready`로 만들지 말고 검수 근거를 남깁니다.
